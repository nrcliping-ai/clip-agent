Clip Agent

Clip Agent is a personal desktop tool for preparing short gaming clips for the owner's own social media accounts.

How it works

  1. The tool prepares a short vertical video clip on the owner's computer.
  2. The owner watches the clip and manually approves or rejects it.
  3. Approved clips are sent to the owner's own TikTok account as drafts (TikTok inbox) using the TikTok Content Posting API (Login Kit, scopes: user.info.basic, video.upload).
  4. The owner opens the draft in the TikTok app, adds a caption and publishes it manually.

The tool never publishes anything automatically and is used only with the owner's own account.
